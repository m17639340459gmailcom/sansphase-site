# 社区装扮素材与拖拽上架

作者或有效总版主进入「社区管理 → 兑换所上架」，打开新物品或已有物品的编辑表单，先选择物品类型。可以从桌面、下载目录或文件夹里直接拖入单个素材文件，不需要先点击上传按钮。拖到打开的商品编辑页面后，接收区域会高亮；文件处理完显示预览，确认名称、分类、价格等信息，再点「保存并应用」。

## 动态头像框

使用正方形、中央透明的 PNG、WebP 或 GIF。动态素材也保持中央透明，网站会把它叠加在真实头像上。商品管理上传技术上限为 25 MiB、120 帧；普通用户及总版主发帖上传图片仍为 2 MiB。后台会验证每一帧是否适合佩戴，拖入操作复用现有 `manage/item-image` 上传接口，不会绕过验证。

文件拖入后自动上传到网站，其他成员才能在兑换后看到并佩戴。上传完成后还需要保存商品；兑换成功后进入背包并自动佩戴。已经有人兑换的头像框不能更换素材，应另建新物品。

## 昵称特效

昵称特效使用配套的 `.json` 文件，大小不超过 64 KiB。拖入后只读取设置并更新预览，不执行文件里的代码。商品保存仍通过现有 `manage/items` 接口，服务器再次校验设置；用户兑换后会应用到自己的真实昵称上。

固定格式示例见 [community-name-effect.json](examples/community-name-effect.json)：

```json
{
  "format": "sansphase-name-effect",
  "version": 1,
  "effect": {
    "style": "shimmer",
    "colors": ["#976223", "#236A7B"]
  }
}
```

当前文件支持单色 `solid`（一个颜色）、双色渐变 `gradient` 和流光渐变 `shimmer`（两个颜色）。颜色为六位十六进制值；额外字段、未知版本、脚本、HTML 和 CSS 文件不能导入。网站只导入并预览制作好的成品，不提供颜色和特效编辑控件；更换成品时拖入新的文件即可。新昵称商品必须先导入有效效果才能保存。

## 操作边界

每次拖入一个素材文件；整份文件夹不会批量上架，打开文件夹后拖入其中的文件即可。文件处理期间不能重复保存；出错后保留原有商品信息和素材，显示原因并允许重试。离开编辑页面后，其他内容编辑器继续使用自己的拖拽行为。键盘和手机用户也可以使用「或选择图片 / 效果文件」入口。

# 内容卡片边角统一（本地待验收）

## 已确认需求

用户明确要求整圈边框粗细一致、四个圆角自然衔接，不是简单把直边加粗。此前本地 c365da8 将共用边框改成 2px，用户反馈直边更粗但圆角问题仍在；该方案未通过视觉验收，未上线。本次替换这项处理。

## 实现与边界

模式：保留现有视觉的局部修正。沿用星空/烟色玻璃、字体、间距、24px 卡片圆角（身份卡 28px）及作者配色。变化程度 1、动效 3、密度 6、图片依赖 7、品牌一致性 10。保护路由、链接、网格列数、图文结构、账号与内容数据。

代码与浏览器确认：旧方案可见边框和 overflow:hidden 同在 GlassSurface，内部内容为 z-index:1；目录海报悬停还单独修改 surface 的 border-color。仅凭 border-width 计算值不能证明四角视觉均匀，此前将问题归结为重复裁切的解释不够完整。

当前方案：

- 共用卡片 host 的 ::after 负责完整 2px 描边，圆角继承 host，覆盖在内容上方，pointer-events:none 不拦截链接。用户继续明确不希望圆角显薄后，将独立轮廓从 1px 调整为 2px。
- host 建立局部层级；GlassSurface 固定在描边下方，保留图片裁切，仅用透明 2px 边框预留位置。
- 去掉共用卡片材质里仅顶部存在的 7% 内侧高光，保留外侧投影，避免顶部单独叠亮。其他弹窗及控件的 smoked-shadow 不变。
- 目录海报悬停使用共用边框色变量，删除 catalog.css 独立表面描边规则；作者自定义边框色优先。
- 工具栏仍无描边；输入框、按钮、头像和后台弹窗不受这条卡片规则影响。

覆盖共用玻璃卡片：博客列表/网格、作品、资料、软件推荐、资源中心、公告与侧栏。不修改第三方组件，不增加业务 JS 或 !important。相比 1px 本地预览，边框预留增加 1px，文本/图片尺寸可有微小变化。

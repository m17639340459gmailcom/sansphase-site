最后权限复核修正了待审或隐藏帖子显示“推荐精选”按钮、但实际操作被服务器拒绝的问题。界面权限标记现在使用异步读取后重新核对的当前帖子状态，推荐仍只适用于已发布且未隐藏的内容。新增四项真实 HTTP 与 DOM 回归，覆盖待审、隐藏、正常已发布以及读取期间被隐藏；关联 196 项通过，最终完整检查已包含这些用例。

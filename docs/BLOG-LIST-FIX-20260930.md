# 博客列表展示修正（本地待审核）

用户反馈：首篇卡片异常放大，文章展示不统一，边角过细；随后明确网格模式没问题，只修列表。

事实：视觉升级在 blog-page.mjs 对第一页首项添加 is-featured，样式把封面变成全宽大图，其余列表项取消卡片材质。不是文章数据变化。

范围：现有页面局部修复。保留新版字体、导航、背景、网格和数据接口；列表恢复统一的左文右图卡片、40% 封面、紧凑标题和摘要、16px 卡片间距。列表使用 2px 边框且由玻璃表面单独裁切圆角，移除重复裁切。标签和箭头不再换行撑高单张卡片。删除已不用的首篇大卡片分支和样式。

设计约束：延续站点色彩和作者自定义设置、24px 圆角，不增加动效或组件；差异程度 2、动效 3、密度 6、图片依赖 7、品牌一致性 10。路由、分页、筛选、正文、账号、VIP 和上传数据不变。

验证：先补首项/翻页/搜索/网格的统一卡片回归用例，确认旧实现失败，再修复。类型检查与构建通过，博客和 DOM 交互相关 30 项检查通过。本地只读预览加载三篇线上公开文章，当前桌面视口三张列表高度均为 226.125px，边框 2px；切换网格后封面高度一致、边框保持 1px；再切回列表正常。不同视口和内容长度仍需按实际内容排版，不能将当前测量作为所有情形固定高度的保证。

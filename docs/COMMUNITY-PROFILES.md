# 社区资料与审核

社区“我的主页 → 编辑资料”位于 `#/community/profile`。头像、个性签名继续使用主站读者账号和既有审核工作流，香港不另建账号或资料副本；审核通过后，主站和社区读取同一份资料。此页面不修改邮箱、手机号、昵称、VIP 或经验。

## 权限

| 操作 | 普通读者 | 现任版主 | 站长 |
| --- | --- | --- | --- |
| 编辑本人头像、个签、头像框、社区背景 | 可以 | 可以 | 切换到个人读者身份后可以 |
| 审核读者头像 | 不可以 | 可以 | 可以 |
| 审核个性签名、个人主页背景 | 不可以 | 不可以 | 可以 |

站长使用同一个作者登录会话，可切换管理身份和真实的个人读者身份。个人身份的头像、个签、昵称和头像框使用独立读者资料，主站和社区互通，不修改 `site_profile` 中的博客作者介绍。社区背景仅用于社区。个人身份可以发帖、回复、签到和编辑资料，不能审核或管理；切回管理身份后恢复站长权限。版主原有的读者浏览视角仍为只读，不影响其现有审核权限。

版主审核权限由当前社区成员状态和会话验证，前端按钮不是授权依据。主站私有资料桥只接受有签名、时效和防重放校验的固定命令，用户不能提交其他账号 ID 代改资料。站长个人资料操作通过明确的 `asReader: true` 命令选择私有绑定的读者，管理命令不能携带这个字段；保存和审核在命令队列内重新验证有效会话与身份。

## 站长双身份配置

主站私有配置中的 `ownerReaderId` 关联一个已验证、未停用的真实 `readers` 实体。配置项必须是明确的 UUID；启动和请求不会自动创建、猜测或重绑读者。香港会话始终绑定原有作者登录，个人操作使用主站签名下发的关联身份；仅修改浏览 cookie 不能获得站长权限或选择其它读者。

首次关联前备份并验证异地副本、在隔离恢复目录运行 `PAYLOAD_CONFIG_FILE=<绝对私有配置路径> node scripts/prepare-owner-reader.mjs --apply --nickname=<2至8字个人昵称>`。在当前发布目录执行时默认公开根目录为 `dist`，其它位置须传 `--public-root=<绝对公开根目录>`。工具沿用 Payload 读者集合及 UID 分配，创建独立资料，不复制博客头像、个签、手机号、VIP 期限或余额。已有关联时只检查，不重置资料；同邮箱实体已存在但未绑定时停止，须核对后明确设置关联。数据库创建成功但配置写入失败时保留该实体，按错误中给出的固定 ID 核对恢复，禁止重复创建。

专属个人身份生命周期随站长账号，不参与普通读者的半年闲置自动清理。普通读者清理规则不变。若绑定缺失或读者停用，个人操作拒绝执行，但仍能切回管理身份；解除绑定或永久清理按持久数据维护流程执行。

个人身份保留已认可的满级、VIP 和全亮徽章展示，其他读者看到相同效果；此展示不写入星尘流水、经验账本、库存或历史成就。实际发帖、签到和兑换仍以专属读者的真实记录计算，余额不足不能借用管理身份余额。编辑草稿按实际角色与 UID 隔离，进行中或结果不确定的写入未处理完时拒绝切换，避免重复扣款或串用草稿。

## 图片与待审资料

头像与背景只接受 JPG、PNG、WebP，原文件最多 2MiB。头像重新编码为 320×320 WebP，背景按最长边不超过 2048 像素重新编码。原文件通过现有流式上传工具处理并移除，不接收任意外站图片地址。

待审头像只供本人、站长和现任版主查看；待审背景只供本人、站长查看。其它成员只读已通过的头像、签名和背景。私有预览响应禁止缓存，未经审核的图片地址也不能绕过权限直接读取。新提交替换旧申请；审核必须针对当前申请，过期或重复决定拒绝执行。驳回背景必须填写理由。

背景只用于社区个人主页，不同步为主站背景。`community_profile_backgrounds` 保存已通过和待审图片引用；图片登记仍位于 `community_images`，用途为 `profile`。默认背景恢复会取消待审和自定义背景，但不更改原有兑换封面权益。

## 头像框

已拥有和穿戴状态仍以香港社区的 `community_owned`、`community_members.frame` 为准，主站不复制库存。主站资料页显示同一头像框，并在现有头像设置区域选择已拥有的框。自定义框图片由主站受限代理提供，只供验证过拥有权限的本人读取，保留动画。

主站认证不依赖远程头像框查询。展示查询短时缓存并合并并发请求，社区暂不可用时不影响主站登录；打开头像设置才读取完整库存，成功穿戴后刷新展示状态。

## 发布与回滚

先使用完整备份工具备份香港旧数据，下载并验证异地副本、隔离恢复；再显式执行 `node scripts/migrate-community.mjs <private-payload-directory>`。迁移只新增背景记录和扩展图片用途约束，保留原有图片、引用与索引。启动不会自动迁移社区表。

备份和过期图片清理均保护已通过、待审背景；已被引用的原图或缩略图缺失时备份失败。账号永久清理按既有规则处理背景引用和图片队列。不要将这些持久数据当旧版本缓存删除。

Nginx 仅对 `/api/community/profile/avatar`、`/api/community/profile/background` 上传放行到 `2112k`，为 2MiB 原文件的 multipart 头留余量，应用仍逐文件限制 2MiB；其它接口不扩大限额。资料接口不开放跨站 CORS。发布代码和迁移都须先在隔离副本验证，保留上一已验收代码及迁移前数据备份。

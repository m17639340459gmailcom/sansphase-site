# 模拟内容预览

服务启动后可打开：[作品](http://127.0.0.1:4177/#/works)、[资料](http://127.0.0.1:4177/#/resources)、[软件推荐](http://127.0.0.1:4177/#/software)、[资源中心](http://127.0.0.1:4177/#/resource-center)、[音乐面板](http://127.0.0.1:4177/#/notes)、[首页音乐图标](http://127.0.0.1:4177/#/home)。

包含 14 项虚构作品、6 份资料、6 项虚构软件推荐、4 项资源中心示例。每项标题均标注“模拟”，详情说明其性质。封面使用项目已有天文照片作为示意，不代表软件截图。部分附件是本站原有 Markdown 示例文档，文件大小由实际文件读取，没有虚构安装包。

音乐使用程序生成的两段低音量试听音，支持播放、暂停、切歌、进度与音量；首页图标会随播放状态变化。试听音不是平台歌曲或实际音乐平台接入，页面不会自动播放。示例数据只由此本地服务加载，正式服务不加载它们。

音乐卡片采用用户确认的黑胶唱片形式：旋转与唱臂跟随真实播放状态，暂停后保留唱片角度。预演中的中心封面为项目已有天文素材，歌曲封面接口尚未接入。时间卡片可切换到内部搜索视图，搜索结果在原卡片范围内滚动，关闭后回到时钟。

可以查看：主图／双列／全部内容的排布、有封面与无封面混排、分类、搜索、分页、网格与列表、正文目录及示例附件下载。

数据由 scripts/fixtures/catalog-data.mjs 提供，仅保存在模拟服务内存中；scripts/catalog-fixture-preview.mjs 不加载 Payload 或作者写入服务，不向正式数据库保存或发布。主站 http://127.0.0.1:4176 的内容不变。

重新启动时，在项目目录执行（本地构建不设置 CDN 地址）：

```powershell
pnpm build
node scripts/catalog-fixture-preview.mjs
```

模拟预览仅用于访客页面展示，不用于登录作者、上传和发布。测试完成后关闭该进程即可，正式内容无需清理。

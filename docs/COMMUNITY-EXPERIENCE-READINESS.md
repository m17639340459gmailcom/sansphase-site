## 计算与通道

| 检查对象 | 当前保障与验证 |
| --- | --- |
| 首次主动访问 | 有效会话、Origin、请求标记和当期公约；请求体必须为空；服务器复核账号邮箱验证、停用和当前 VIP。账号、北京时间日期、会员日和经验发放在同一 SQLite 事务去重 |

| 经验来源 | 公开有效内容、审核、有效回复和采纳的服务器事件；每日种类限额、唯一内容引用；不接受客户端金额、日期、倍率或等级 |
| 删除和恢复 | 删除、隐藏、回复失去资格、整帖失效及移入私密板块回收相应来源；原领取证据保留，恢复不重领，不返还当天名额 |
| 星尘 | 仍由独立服务器账本结算；有效行为每日发行上限、引用去重、冲正和限额沿用既有规则。VIP 经验倍率不增加星尘 |
| 点赞 | 同一账号与目标唯一，不能自赞；重复请求及取消后重新点赞不发星尘或经验；计数来自数据库，不能用请求体提交赞数或其他账号 |
| 签到和兑换 | 服务器决定奖励和商品价格；伪造奖励、余额、身份、VIP、价格或负金额不改变服务器计算；已有请求去重与事务保留 |
| 权限与数据 | 授权仍由服务器验证；其他人的流水、订单、收货信息、未解锁提示词及私密板块不能靠前端改变量取得；相关原有服务回归继续通过 |
| 网页身份与顺序 | 主动访问响应绑定服务端公共 UID；跨标签账号切换不匹配时清理并刷新；跨日旧响应不能覆盖新快照；缺失/非法级别不制造个人等级 |
| 静态文件 | 新增私密路径、凭据、数据库、调试映射及源目录拦截；解码后检查，屏蔽 Windows 数据流路径；真实文件路径不得逃逸 public 根目录，目录链接不能暴露外部文件 |

| 项目 | 已确认的现状 | 正式切换前的通过条件 |
| --- | --- | --- |

| 正式可发布版本 | Git 目前未跟踪 V3 目录，正式主站发布脚本只接受 V1/V2，V3 是独立的 Next 前端 | 从已跟踪的源文件和锁文件干净构建。正式域名交付 V3，原主站接口、管理台与分享路径按既有同域规则接入。检查交付清单，清除演示内容、样例联系人、无关资源和本地端口配置 |
| 搜索引擎和缓存 | 本地 V3 屏蔽搜索引擎，站点地图使用本地域名，部分页面缓存按长期静态预览配置 | 正式站公开页面和文章采用正式域名与正确的索引规则；更新、撤回及时生效；登录态、草稿和受限内容无共享缓存 |
| 依赖检查 | 原共用后端锁文件检出 4 条高危公告。修复候选的依赖审计没有高危或严重公告 | 锁定经核实的修复版本，验证实际加载版本，并重跑构建、功能回归与生产依赖审计 |

## 原接入顺序

1. 先确定主站页面与现有同域接口的分流，同时处理已知依赖审计项。用一篇已有文章跑通「旧地址 → V3 真实正文 → 分享卡片 → 返回主站」作为第一条验收链路。
2. 用同一接法覆盖首页发布动态、作品、资料、书籍、软件和搜索。复用原注册、找回、个人资料、作者和管理服务，在 V3 内补齐缺少的入口，再验证香港社区往返。
3. 在预发布环境按表走完公开、读者、VIP 和作者流程，检查旧链接、性能和回滚，作为正式域名切换到 V3 的放行依据。

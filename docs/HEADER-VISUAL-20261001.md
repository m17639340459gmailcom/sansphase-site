# 本地顶栏与字标修正

起点：`9aea200`。用户反馈切换页面时顶栏跳动，以及“相”比“無”明显偏胖。仅本地修正，不部署、不推送，不改黑洞与持久数据。

## 核实结果

- 独立临时 Chrome 在 1600×1000 窗口读取实际字形来源：顶栏“無”为 SimSun，“相”为 Source Han Serif SC Heavy，确实发生了逐字字体回退混用。不是单个字设置了不同字号。
- 导航容器在首页 y=21，内容页 y=20.5；固定高度内新增 1px 底边框造成半像素偏移。横向位置及宽度在该测试窗口稳定，未将滚动条认定为本次已证实原因。
- 旧高亮逻辑在重建顶栏时复用上一页/悬停的位置，下一帧再启动滑动。页面过渡快照和高亮自身动画不同步，有补跳和错误高亮闪现的条件。

## 改动与边界

- 顶栏始终预留 1px 底边框：首页透明，内容页使用原颜色，保持布局高度一致。
- 字标使用单独字体变量，优先选用当前“無”实际使用的 SimSun；应用于顶栏、首幕标题及加载字标。保留原字号、字重、字距，不横向压扁“相”，不改正文与其他页面标题。使用系统字体，其他系统的实际字形仍可能有所不同。
- 高亮在页面重建时同步定位当前项目，不保留旧页位置；保留悬停和键盘聚焦滑动、移出复位与 resize 重算。删除旧缓存及延后一帧分支。
- 导航模块按现有规则迁移为 `nav-slider.ts`，`.mjs` 只作源码适配入口，构建仍输出原路径；未新增另一套导航组件。

## 验证

先补切页即时定位、非导航页面不闪现旧高亮用例，旧实现两项失败，修正后通过。导航、页面过渡、样式组合、构建同步共 10 项检查通过，类型检查及完整构建通过。构建首次因新适配入口 CRLF 与既有精确约定不符而失败，已按既有 LF 格式修正；未放宽构建校验。

真实浏览器再次切换首页、博客、作品、资料、软件推荐并返回：首页与内容页的导航矩形均为 x=541、y=20.5、width=492（本测试窗口），顶栏两个字实际字体均为 SimSun。诊断截图及坐标记录在忽略目录 `outputs/black-hole-20261001/nav-*`，不提交浏览器资料或真实账号信息。此本地预览为画面服务，不代表生产内容/账号接口验收。

另在窄窗口验证折叠菜单打开、切换博客和作品、返回首页，顶栏宽度稳定；该独立 Chrome 的最小布局宽度实际为 500px，不能据此声称完成真实手机触屏验收。

# 社区分支集成记录（2026-10-02）

伙伴分支 `feature/community` 的源提交为 `051d254`。社区在本地集成及 GitHub 合并，**尚未部署生产**；线上仍是 [交互修复版](INTERACTION-RELEASE-20261002.md)。后续先本地修改和验收，再安排单独的社区上线。

## 范围与规则

社区包括版块、帖子和回复、签到、星尘、兑换、成员页、通知及管理。共享真实账号体系，但社区权限和数据访问由独立服务模块处理；生产启用前需要显式数据库迁移，不能把合并代码等同于社区已开放。

2026-10-02 用户明确选择伙伴的新规则：帖子与回复删除后保留审核记录；仍有有效社区内容的账号跳过连续 30 天未登录清理，有效 VIP 原有保护继续保留。保留记录会占用空间，后续需单独评估容量及审核记录保留期。

社区星尘兑换不是人民币充值。私人 VIP 支付与订单演示继续留在本地，不进入公开提交，也未部署。

## 合并中的修正

- 保留已上线的黑洞、编辑器、顶栏和导航点击修复，不恢复旧版全屏截图转场。社区内部保留自己的页面入场；跨站导航复用即时交互的真实内容淡入。
- 清除未使用的草稿读取函数及兑换展示参数，严格类型检查通过；没有关闭检查或用 `any` 绕过问题。
- 修复帖子详情响应透传存储对象的问题：原先虽然 `meta.prompt` 被隐藏，内部 `fullMeta.prompt` 仍返回完整付费提示词。改为明确列出公开摘要字段，完整提示词仅走原有权限分支。先补完整响应不泄露的失败用例，再验证作者可读、解锁后可读及未解锁不可读。
- 社区入口的旋转装饰伪元素会以旋转方形边界撑宽手机页面。将裁剪限定在装饰容器，保留轨道亮点，不以全局隐藏横向滚动掩盖内容问题。
- 更新旧转场测试与文档状态，保留伙伴提交历史。

## 验证与限制

- `pnpm build`（包含严格类型检查）通过。
- Chromium UI/GPU 环境下全套 474 项测试通过，无跳过；覆盖社区服务、迁移及升级、积分事务、权限、审核、兑换与原站点回归。
- 独立本地夹具使用临时数据库和虚构账号。1440px、390px 检查入口、社区首页、版块、签到、星尘、兑换与我的兑换、排行、通知、公约、发帖及站长管理页，并操作签到。未连接真实生产数据库。
- GitHub 自动检查需通过后才能合并。浏览器证据和测试日志仅存本地，不公开真实用户资料。

这不是所有设备无缺陷的承诺。Safari、真实手机、生产数据迁移预演和更大社区数据量的性能验证仍属于正式开放前验收；此次不执行生产迁移或再次部署。

# 社区当前界面与维护

2026-10-05 用户确认采纳 4214 的当前社区版本。深色与明亮模式属于同一套界面，从正式源码 `D:\博客` 维护；早期演示方案和逐轮开发说明可从 Git 历史及维护归档恢复，不再作为当前入口。

## 界面约定

- 深色使用深蓝、暖金与星空；明亮使用米白、灰蓝、金棕及浅色星雾。保留现有字体、SVG 图标和签到徽章，不新增生成组件。
- 电脑顶栏 72px、手机 64px；左栏 156px，右栏 280px。1240px 收起右栏，1000px 收窄左栏，700px 使用手机布局。
- 内容区保持开放，帖子之间使用博客边框颜色的 2px 分割线。图标及昵称尺寸、选中反馈、按钮对齐和兑换卡片大小由共用样式管理，主题样式负责材质配色。
- 兑换陈列列宽最高 176px，展示区 112px，同组商品等高，基准最小高度 236px。说明可展开，限制、库存、价格和操作始终可读；头像框共用预览字为「無」，不改实际用户头像。
- 左侧进入其他页面从顶部显示；排序、筛选、日历翻月、语言、主题和同页标签操作保留阅读位置。主题切换保留当前 DOM、草稿、焦点和滚动位置。
- 滚动条初始隐藏，滚动时显示，静止 5 秒隐藏。账号菜单点击外部关闭，成功提醒居中自动关闭。
- 帖子详情右侧为作者、作品信息、提示词和同板块帖子；窄屏移回内容区。原权限、解锁和操作保持有效。
- 输入区最小高度 152px，随内容长高，没有原生拖拽角；聚焦只改变原边框，不叠加第二层描边。

## 业务边界

作者设置提示词价格为 5–50 的整数。普通用户和 VIP 上传、粘贴或发送的单张图片上限为 2 × 1024² 字节；网页和服务器共用 `src/upload-policy.mjs`。作者沿用原有的 25MB 技术上限。已有图片与真实账号数据不因整理而改写。

每日签到 +1，自然月满勤另加 +5，补签计入满勤；站长不参与签到。正文、回复图片、历史内容兼容、会员权限及审核继续由既有业务模块管理。未来上线前须按维护指南备份并迁移社区表，不能以本地预览代替上线验证。

## 模块位置

| 模块 | 职责 |
| --- | --- |
| `src/community.css`、`src/community-layout/feed*.css` | 共用尺寸、帖子、控件和物品陈列 |
| `src/community-layout/stable-frame.ts`、`stable-frame.css` | 三栏、导航、阅读位置与滚动条 |
| `src/community-layout/appearance.ts`、`appearance.css` | 主题切换、主题材质与配色 |
| `src/community-pages.ts`、`community-post.ts` | 页面和共享物品预览 |
| `src/community-management.ts`、`community-management.css` | 独立作者/版主管理布局、浏览身份提示和商品图片预览 |
| `src/community-shop-editor.ts`、`community-name-effects.ts` | 作者分类／装扮上架表单、佩戴预览及深浅主题昵称配色 |
| `src/community-ui.ts`、`community-compose-editor.ts` | 交互、草稿和图片编辑 |
| `server/community-*`、`server/payload/community-migration.ts` | 权限、内容、图片与迁移 |

作者可新增商品分类，拖入制作好的透明静态／动态头像框和受限 `.json` 昵称效果文件；上架页导入与预览，不提供颜色编辑器。兑换、背包、佩戴／取下和社区展示沿用共有装扮链路。管理页表格、批量审核和固定理由弹窗使用同一套间距，内部操作保持阅读位置。处罚记录按用户更正持续保留，展示执行中、到期与解除状态。具体规则见 [上线前与身份预览](COMMUNITY-PRELAUNCH.md)。

构建按 `scripts/compose-community-styles.mjs` 的明确顺序组合样式，不依赖预览注入或版本参数。每次打开或刷新页面默认深色，旧 `communityTheme` 参数和已存偏好不决定初始主题；`v` 只是旧预览链接标记，不选择另一套代码。手动切换后的主题在本次页面内供社区内容和管理台共用，路由及语言切换保留，不写入长期存储，也不影响主站主题。

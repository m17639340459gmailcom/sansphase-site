## 已确认规则

- 单房间群聊，文字和静态 JPG、PNG、WebP 图片；不加入语音、视频、文件、私聊或自动审核。
- 普通用户需要有效 VIP；作者、总版主、版主可凭有效管理身份进入。
- 协管不因职务获得准入；有有效 VIP 时按普通会员进入，没有公告或管理撤回权限。
- 用户只能在服务器记录的发送时间起五分钟内撤回自己的消息；作者、总版主、版主可以处理他人的消息。
- 作者、总版主、版主可以发布公告。未进一步授权的编辑范围采取保守默认：版主仅管理自己的公告，总版主和作者管理全部；单条置顶，普通版主不能顶替他人已有置顶。后续产品确认可调整这一策略。
- 禁言拒绝发言、图片上传、公告写入，仍可撤回本人五分钟内的消息。
- 界面沿用已确认的配色、布局、QQ 式固定高度输入区和主题滚动条；输入内容溢出只在输入区内滚动。

## 复用与边界

实时连接使用锁定版本的 Socket.IO 及客户端；压缩和上传复用 Compressor.js、Sharp、Busboy 及现有薄适配。`communityService.teahouseIdentity` 和 `teahouseAuthors` 复用现有账号、任命、真实 VIP、昵称、头像和当前佩戴图标。客户端上报的身份、VIP、角色均不构成权限。

撤回按钮的时间显示以现有 session 响应的 `serverTime` 为基准，通过 `performance.now()` 前进，回到前台和重连时重新同步；设备校时不能使撤回按钮提前失效。服务器仍独立执行五分钟期限及管理权限，不接受客户端计时作为授权依据。

HTTP、连接、每个变更和私有数据投递前核对当前身份；闲置连接每十五秒复核，不能宣称界面在撤权瞬间断开。每次长连接核验建立独立的真实会话上下文，不复用握手时的权限。被动连接、收消息和心跳不会记作论坛访问，也不续期真实生产会话；成功的真实写入才记录会话活动。

消息带唯一提交编号及修改序号；重试去重，历史按批读取，重连从数据库补拉。不开 Socket.IO 原文恢复缓存，避免撤回后重播旧正文。广播、ACK、历史资料补齐等异步步骤结束后重新读取最新消息状态。

发送确认等待发送者自身核验，不等待全体接收者。后台合并最多 64 个待广播消息编号，超过时使用不含正文的同步提示，让在线页面按修改序号补拉；不堆积正文任务。临时身份桥故障或限流暂停私有内容投递并退避重连，真实退出、VIP 失效或权限撤销停止访问。作者／个人身份切换会断开旧连接，清理旧草稿和附件，以新连接重新核验，旧响应不能覆盖新身份内容。禁用传输层自动重连；断网恢复先通过 HTTP 确认当前身份，再创建新连接，避免旧发送缓冲以新身份重放；同身份恢复保留草稿，旧连接的回执不会清除当前草稿。

## 撤回与文件生命周期

聊天库与论坛 `content.db` 分离，使用 `db/chat.sqlite` 和 `images/`；不生成聊天备份。撤回在事务中删除正文与附件关联，仅留下不含原内容的消息占位及待删附件编号，随后删除图片文件；失败删除会重试，重启后也能继续处理。没有发送的上传一小时过期并清理。

SQLite 开启 `secure_delete` 和 DELETE journal，减少空闲页与 WAL 残留；这不等于存储硬件取证级擦除。不在日志记录正文。不把聊天内容混入论坛现有备份。服务端撤回不能抹除收件人自行保存或截图的内容。

## 正式配置与发布

用户已授权完成上线检查后交付。香港私有配置增加 `teahouse: { "enabled": true, "directory": "/var/lib/sansphase-community/teahouse" }`；默认关闭。该目录必须与社区数据、上传和公开资源目录独立，不能互相包含或经符号链接指向其他目录。部署先创建服务账号所有、权限 700 的空目录，再使用新源码和私有配置显式运行 `node scripts/start-community.mjs --prepare-teahouse`。此命令只准备茶室，不迁移原社区库；正常启动要求表和索引完整，拒绝自动建库。

正式入口 `/teahouse` 使用现有社区会话，`/teahouse.html` 同样受保护。开启后社区会员茶室导航指向聊天室，原会员讨论板块和真实帖子保留。正式启动不加载本地身份选择器、演示账号或预填消息；测试库不复制到服务器。生产初始聊天库为空，第一条消息由真实成员发送。

Nginx 为 `/api/teahouse/socket.io/` 配置 WebSocket 升级和 75 秒代理读超时，图片上传使用独立的请求体范围和连接限额。配置依据 [Socket.IO 官方代理说明](https://socket.io/docs/v4/reverse-proxy/)，其余社区接口维持各自限制。主站不启动聊天室，也不复制账号库。

未撤回消息暂按正常持久数据保留，未增加未经用户确认的自动删档期限。主站账号删除通知香港后，茶室以持久删除标记阻止旧会话写入，清除该读者正文、附件和公告；物理文件未清理完成时返回失败，沿用主站任务重试。在线页面同步移除相关内容，迟到的旧历史不能恢复它。

聊天目录不进入社区备份清单，也不得添加到服务器全量/异地备份任务；恢复社区备份时强制关闭茶室并去掉原目录引用，防止恢复演练连接在线聊天库。此选择意味着服务器存储损坏后聊天记录可能无法恢复。回滚只切换代码和配置，保留上线后真实聊天数据，不用旧备份覆盖它。

`pnpm test:teahouse` 运行身份、持久层、实时服务、竞态和客户端状态回归；`pnpm check:types` 验证全库类型。测试通过不替代两端实际浏览器验收和真实部署环境压测。

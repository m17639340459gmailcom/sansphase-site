# 公开博客阅读与搜索入口

发布记录（2026-10-12）：源码 `19ed72a` 已部署至主站及香港社区，运行版本为 `1.0.0-rc.1-0aff91f2f6b64743`。两端从同一源码清单在空目录构建，静态资源清单一致；未执行数据库迁移或覆盖生产数据。发布状态以私有发布回执及 `/healthz` 为准。

## 地址和权限

- `/blog/<slug>` 返回同一篇已发布博客的完整 HTML、标题、简介、Open Graph、Twitter Card 和自指 canonical。slug 对应公开 DTO 的 `id`，不是数据库 UUID。
- 旧 `/#/note/<slug>` 继续可用。浏览器接管普通链接，保留原来的页面切换、返回与前进后退；服务器无法读取旧地址的 hash，不做虚假的逐篇 301。
- `/share/blog/<slug>` 仍是已确认的横向分享卡，目标改为普通正文地址；卡片本身 `noindex`，仍允许聊天平台读取元信息。
- `/sitemap.xml` 根据当前公开快照列出主站入口及有效博客；不编造 `lastmod`。`robots.txt` 的站点域名来自运行配置，不信任请求 Host。
- 草稿、未来发布、撤回、预览、会员资源和社区私有正文不会通过新地址开放。正文输出前再取当前发布快照，正文、元信息和初始数据同版本。个性化 HTML 仍为 `private, no-store`。

这补齐搜索引擎可读取的内容和发现入口，不承诺收录、排名或微信自动生成聊天卡片。

## 页面复用与启动

`article-page.ts` 是服务端与客户端的同一份正文模板；`blog-reading-sidebar.ts` 复用原作者、音乐侧栏；目录和音乐初始结构也复用客户端模块。服务端提前输出原阅读布局，客户端保留首次正文节点并接管交互，避免先输出首页或重复请求正文。

旧 `.mjs` 兼容入口仍是必要源码。含包依赖的 UI 模板通过既有 esbuild 打包；纯 TypeScript 浏览器模块在 `typed-browser-modules.mjs` 与构建清单登记。不要直接修 `dist`。

## 内容读取优化边界

公开列表与详情的 ETag 基于实际响应字节。无关账号写入导致快照重建、但响应未变化时仍可返回 304；判断 304 前必须取得当前有效快照，不能跳过撤回和权限检查。

同一次 `publicData()` 重建按媒体 ID 合并读取，下一次重新读取；沿用 Payload `select` 裁剪公开投影不使用的字段。缺失图片与缺失必需附件仍遵循原有不同处理方式。

本轮没有改变 `PRAGMA data_version`、定时发布与缓存有效期，没有数据库迁移，没有删除旧完整内容接口。数据库分页属于后续独立评估，必须保留搜索、人工排序、分类统计及完整媒体授权语义。

## 维护与验收

社区商品素材与管理成员的局部状态由各自 controller 持有；身份、统一请求、事件注册、页面绘制、缓存和滚动协调仍由 `community-ui.ts` 持有。拆分代码不等于浏览器下载量自然减少。

必要验证包括：

1. 匿名新旧正文一致，真实地址关闭 JavaScript 仍含完整正文；旧链接、分享、返回、前进后退与刷新正常。
2. 撤回、定时发布、作者预览、附件与会员授权保持原边界；旧 ETag 不让已撤回内容重新公开。
3. 桌面和手机深浅主题下，人为延迟应用脚本，正文节点、位置和图片稳定；目录、播放器、分享、复制与键盘操作不重复挂载。
4. 商品上传、拖放、管理成员查找、保存期间切页或切身份、清理监听、被动刷新及佩戴相关回归通过。

本地真实浏览器回归使用隔离的浏览器资料目录和演示数据，不连接用户生产数据库；上线后的浏览器检查另使用独立资料目录，只匿名读取公开内容和入口。性能样例的媒体 Local API 调用次数不能当作线上 SQL 总数或直接换算成用户提速百分比。

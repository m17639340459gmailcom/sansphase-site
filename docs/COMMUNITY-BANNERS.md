# 社区横幅设置

首页和每个板块保存独立的顶部推荐。首页只由作者配置；板块由作者和实际负责该板块的版主配置。读者浏览视角不能修改。服务器按真实账号和当前任命核对权限，不能靠修改页面参数扩大范围。

## 使用

从账号菜单进入管理台，打开「横幅设置」，选择首页或板块。版主只会看到自己的负责板块。

横幅可选择帖子，或直接上传独立图片，每处最多五张，可以混合排列。帖子搜索可以找到不在首批结果中的帖子；展示标题可修改，留空使用帖子原标题，点击后进入该帖。帖子未指定封面时使用帖子首图，无图使用现有星空背景。独立图片不需要创建帖子、不接受外链；标题可留空，显示图片本身，不生成帖子跳转。

图片可以拖拽或选文件，支持静态 JPG、PNG、WebP；作者沿用既有上传上限，其他管理账号每张不超过 2MB。新增独立图片时须上传成功再保存。既有的帖子选项和自定义封面仍可继续使用，后续置顶、精华与独立图片均互不影响。

多张横幅每 5 秒按所设顺序切换到下一张，最后一张后回到第一张。仅有一张不启动计时器。按作者要求不展示箭头、计数或暂停/播放按钮，也不保留控件占位；仍可原生横向滑动或使用左右方向键。鼠标停留、焦点在横幅内、拖动中、页面不可见或横幅离开视口时暂停，结束交互后重新等待 5 秒；开启减少动态效果时不自动轮播。离开页面释放计时器和监听。

上下移动调整顺序。「保存横幅」只保存当前位置；切换位置保留当前浏览内的各处草稿。「取消修改」恢复该位置的已保存设置。清空并保存会隐藏该位置的横幅，不留下大块空展示区。首页、其他板块和帖子列表的置顶、精华不随之改变。

两位管理者同时编辑时，服务器只接受匹配当前版本的保存。后来提交的草稿会保留并提示冲突，需明确取消并读取最新配置后重新编辑，不自动覆盖别人刚保存的设置。退出账号清除草稿，迟到的上传或保存响应不进入新账号。

## 实现与维护

- `server/community-banners.ts`：独立范围、图片或帖子选择顺序、版本事务、帖子可见性及图片授权。
- `src/community-banner-controller.ts`：按位置保存草稿、搜索、拖拽上传、保存和冲突处理。
- `src/community-banner-editor.ts`、`src/community-management.css`：管理表单、预览与响应布局。
- `src/community-frame-banners.ts`、`src/community-layout/feed-showcase.ts`：授权配置与现有横幅展示。不会从帖子置顶自动补选横幅。

模式为现有管理台的功能扩展，保留现有金色/蓝灰配色、衬线标题、控件和深浅主题变量。表单区和候选区间隔 22px，条目内间隔 18px，窄屏叠列。没有额外输入框聚焦描边或全页滚动重置。

现有 `manage/banner-image` 上传和 `manage/banners` 保存接口继续使用，不增加另一套上传或管理接口。保存数据为 `{ scope, version, items }`。帖子项继续使用 `topicId:string`、`title` 和 `cover`，可省略 `kind` 或传 `'post'`；独立图片项必须使用 `kind:'image'`、`topicId:null` 和已上传的 `cover` 图片 UUID。独立图片的 `board` 由服务器按范围确定：首页为空，板块为该板块 ID；读取时 `topicTitle` 为空、`topicImage` 为 null、`image` 等于 `cover`。未上传的本地编辑草稿可以暂时 `cover:null`，服务器不会保存这种独立图片项。

上线前仍需按维护指南备份持久数据并执行既有社区迁移工具。独立图片迁移将 `community_banner_entries.topic_id` 从 `TEXT NOT NULL` 改为可空，保留原有配置行、顺序、版本、索引、唯一约束和触发器。`UNIQUE(scope,topic_id)` 继续禁止同一范围配置重复帖子，允许多个独立图片的 NULL 关联，不生成占位帖子。迁移前保存备份，事务内复制原列和行，提交前检查外键，失败回滚，重复执行不再次迁移。首次社区配置仍只快照一次旧推荐内容；后续置顶不会改变该快照。

上传图片按当前管理身份和范围授权，只能新增自己为该范围上传的图片；接手管理时可以保留该范围已经配置的封面。板块查看权限同时控制独立图片横幅和图片读取；帖子隐藏、删除、移动或失去查看权限时，其横幅和封面访问一起停止，不影响同范围的独立图片。过期上传清理、账号永久清理及备份均保护仍被配置引用的图片；上传过横幅的版主账号被删除后，已发布的独立横幅作为社区共有配置保留。

部署时先验证异地备份和在新目录恢复的结果，再显式执行社区迁移；保留实际部署、数据核对和回滚回执到私有维护目录，不将账号、配置、上传文件或维护回执提交到源码库。

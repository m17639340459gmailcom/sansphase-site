# 2026-10-01 作者编辑器粘贴与弹窗滚动修正

状态：仅本地完成，未部署、未推送。生产文章、账号及上传文件未操作。

## 已确认的问题

先前仅测试短句和长文，未覆盖空剪贴板，结论不完整。追加真实 Chromium 检查后，空粘贴可使作者弹窗 scrollTop 从 499/493 直接变为 0，正文没有增加。

当前安装的 ProseMirror 1.42.3 在剪贴板解析无内容时进入 capturePaste：创建临时固定定位、屏幕外的可编辑节点，focus 后稍后恢复正文焦点。此行为在本站毛玻璃作者弹窗内触发滚回顶部。长文是另一条路径：粘贴事务带 scrollIntoView，原行为滚至末尾光标。

作者弹窗原本由同一元素负责圆角边框、毛玻璃和滚动，轨道紧贴右边缘；没有稳定滚动槽。这是布局配合问题，不能仅通过加粗卡片边框修正。

## 修正范围

- 新增独立 TypeScript 模块 author-editor-viewport.ts，以现有编辑器扩展机制处理；不修改第三方依赖。
- 对有剪贴板数据、无文件且解析结果为空的粘贴直接消费，避免隐藏输入区夺取焦点。不清空原选区内容。
- 仅粘贴事务及其附加事务保留当前视口，下一次正常输入、撤销或导航恢复编辑器原有光标滚动规则。粘贴内容及链接解析仍由原有编辑器处理。
- author-frame 负责原有外框与视觉，author-panel 保持为已有滚动容器；滚动区域向内留 8px，使用透明轨道及稳定滚动槽，不新增第二层边框。
- 同步调整内部间距与吸顶工具栏偏移，保留原来的弹窗宽度、最大高度和居中方式；关闭、未保存提示、拖动排序、图片插入仍复用原来的 author-panel。
- 没有叠加延时 scrollTop 回写补丁，也没有全局关闭正常输入的自动滚动。

## 验证

1. 新增真实浏览器回归用例，在修正前因“empty paste moved panel: 677 -> 0”失败；修正后通过。覆盖博客、作品、资料、软件推荐、资源中心五类正文；空粘贴、长文、选中文本时空粘贴、清空后空粘贴、继续输入和外框内缩均通过。
2. 常规作者 UI 测试追加空粘贴不转移焦点、不变更正文的断言，无浏览器环境也执行。已有 Markdown/富文本链接、撤销、格式、章节与保存集成测试保持通过。
3. 本地真实 Chromium：1280、768、390 三种宽度，空/单段/30段粘贴共 9 组，弹窗及背景滚动位移均为 0，无页面异常。
4. 三种宽度检查作者首页、内容列表、个人资料和编辑窗口，共 12 组；内缩几何边界、无横向溢出、长表单底部滚动不传给背景、未保存提示可见均通过。截图与数值位于本地 outputs/editor-paste-20261001，不公开上传。
5. pnpm build 通过；启用 UI 与 GPU 浏览器变量后全套 384/384 测试通过，无跳过。

另外检索了全站滚动容器：用户管理外壳、管理详情弹窗已有外框裁剪与内部滚动分层；正文代码块、表格、书籍目录有各自滚动用途，本轮未统一替换。不能将作者窗口检查说成全站所有弹窗或所有浏览器的逐一实测；Firefox、Safari 和手机软键盘场景尚未单独验收。

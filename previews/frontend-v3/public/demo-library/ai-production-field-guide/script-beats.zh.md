# 安排三十秒的脚本节拍

《末班信号》是一段虚构短片。主人公在几乎空无一人的站台等末班车，最后亮起的不是列车灯，而是离站指示牌。观众只需要跟上一次明确的期待变化。

## 给三个时间段各写一个任务

| 时间 | 观众看到 | 观众开始猜测 |
| --- | --- | --- |
| 00–10 秒 | 站牌、空轨道、远处一点亮光 | 列车就要开进站台 |
| 10–20 秒 | 亮光变得稳定，人物缓缓低头 | 亮起来的东西可能在站台上 |
| 20–30 秒 | 离站牌亮起，远景逐渐安静 | 班次已过，这里只剩下一次道别 |

## 先用平面草稿试读

把三段排成一张纸，从左到右看一遍。不加解释性独白。邀请一位同伴复述哪里发生了变化，如果他说不出来，就调整第二段的信息顺序，再设计运动。

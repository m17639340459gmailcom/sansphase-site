# 成片发布前的两遍检查

给《末班信号》的公开演示版单独导出一份预览。锁定同一个版本号，这样两遍核对记录的是同一份成片。

## 第一遍像普通观众那样看

从第一帧看到黑场，中间不暂停。记下第一次知道“车不会来了”的时间。如果这个时刻已经到了结束字幕，回到 10–20 秒检查人物视线和站牌线索。

## 第二遍按交付项检查

- 核对人物低头与声音变化是否同一节拍。
- 看两条字幕是否来得及读完，以及小屏是否有足够边距。
- 检查中段亮光是否意外闪动、黑场是否残留一帧画面。
- 对照导出清单检查分辨率、比例和文件命名。

给每项修正标记发生时间和复核结果。修改后至少重看受影响的两个相邻镜头。

# Build a traceable source index

When a project ends, the footage is often easier to find than the reason a particular cut won. A source index connects a file to the decision it supported.

## Keep the sources you would look up again

| ID | Source | Question it answered | Location |
| --- | --- | --- | --- |
| W-R01 | Desk lighting sketch | Which side held the reflector? | Process diagrams |
| W-R02 | Three raw frames | How did distance affect the rim? | Experiment one |
| W-R03 | Overcast follow-up list | What should happen next? | Next actions |

### Test the index

Open any row and find the matching source within a minute. Update the row if the file is renamed. When a source is withdrawn, preserve a short reason until the project closes.

## Record where the result applies

This index describes the fictional Window Light setup. Test the distance again if you switch to a glass cup or a different light source.

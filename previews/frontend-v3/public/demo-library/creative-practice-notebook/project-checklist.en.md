# Write a project case note

The Window Light case page answers a small question. How do you keep one edge visible in a fixed tabletop composition? Open with frame W02 so the result can speak before the explanation.

## Follow the reader's questions

1. Introduce the light source, desk and intended outcome in one paragraph.
2. Show W02 beside a sketch of the lighting setup.
3. Compare W01 in one small pair and explain where to find the raw frames.
4. Close with the deliverables and the overcast variation still to be tested.

## Finish with a release checklist

The sample delivery includes one lead frame, two comparisons and a setup note. Image descriptions should name what changes, such as “the right edge is distinct with the white card fifteen centimeters away.” Record the export date and where to find the next review.

# 把学习记成可以重做的一次实验

《窗边光线》是一组虚构的桌面摄影练习。目标是在下午四点保留杯口轮廓，同时让窗框之外的背景安静下来。正式拍摄之前，先用三张照片把这个问题测清楚。

## 写下唯一改变的条件

相机固定在桌沿，快门、光圈和焦距都保持一致。依次把白纸放在杯子右侧的五厘米、十五厘米和三十厘米处，画面编号为 W01、W02 和 W03。三次使用同一张纸，避免把纸张大小的影响误记成距离的变化。

| 画面 | 调整 | 肉眼看见的差别 |
| --- | --- | --- |
| W01 | 反光纸离杯子五厘米 | 杯口亮，桌面的细节被抹平 |
| W02 | 离杯子十五厘米 | 轮廓完整，纸张反光柔和 |
| W03 | 离杯子三十厘米 | 杯口右侧开始和背景融在一起 |

## 给下次留下开工条件

下次先复现 W02，并在阴天重做一轮。若光线方向变了，要把照片另存为第二组。保留三张原片、一张桌面俯拍和这页记录，就能在隔周之后接着做。

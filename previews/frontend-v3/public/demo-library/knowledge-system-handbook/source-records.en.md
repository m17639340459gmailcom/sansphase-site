# Connect a decision to its source

Star Atlas includes one provisional conclusion: the samples captured later at night have clearer edges. Checking that claim a week later requires both the source and the conditions used for comparison.

## Separate observations and interpretations

| Layer | Example |
| --- | --- |
| Original observation | Two frames from W09 |
| Conditions | Same focal length, different lighting |
| Current interpretation | Indoor reflections may explain the difference |
| Disconfirming result | The edge difference persists under matching light |

## Leave a path back to the record

Write the short conclusion on the project page and point to its record ID. Keep the time, sample group and filenames, and use the existing tag system to find them. Update the review status next to the conclusion if the source is corrected.

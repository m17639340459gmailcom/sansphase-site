# Set up an inbox you can clear weekly

Star Atlas is a fictional knowledge-base exercise that starts with twelve scattered observation notes. The aim is to separate active work from lasting material before another week begins.

## Capture two fields first

Write a title and a source, such as “North window reflection, from observation W09.” Mark an unclear source for review. Give your own inference a separate line so it does not become mistaken for existing evidence.

## Pick from three destinations once a week

Archive material that belongs on the project page. Move points that need a check into the task list. Hold unsourced material you do not need soon and review it on a defined date. When several notes record the same thing, keep the one nearest to the original.

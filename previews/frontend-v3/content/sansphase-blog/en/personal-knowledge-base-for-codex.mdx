> Fictional demonstration · The search corpus consists of invented local production notes.

Start with four short notes: two storyboard descriptions, one screening review, and one change log. Ask a concrete question: “Why did the third sign disappear from the final shot?” If an answer cannot identify the original record, the next person still has to search from the beginning.

## Put a usable address on each source card

A source card is short: topic, record ID, quotation or section, and scope. Sample S03 says the third sign repeated information already covered by the voice, so the frame kept only the conclusion. The card applies to this fictional cut. It cannot tell someone whether a third panel was removed from the project poster.

## Try two search methods against the same question

Searching for “third sign” finds the screening note directly. Rephrasing to “is something missing from the final section?” brings up two unrelated boards. The source index uses “final shot,” “sign,” and “conclusion.” Checking that scope is enough to reach the right record again. Keep both search results to see whether an error comes from words or from missing evidence.

## Leave an explicit gap for the next handoff

A second question asked who had approved the final cut. The four sample files do not contain that field, so the answer remains open. Adding a review record would help more than changing how the search ranks existing files.

### Write down exactly what the exercise covers

This trial contains four records and three queries. It demonstrates source checks and handling unknowns. Broader search coverage would require a larger corpus.

# SANSPHASE — 作品集 · 版本4（参考站排版 + 自有首屏）

原型，不是正式源码；正式源码一行没改。和版本1–3 并排对比用。

## 运行

```bash
node outputs/portfolio-version-4/serve.mjs
```

打开 http://127.0.0.1:4284/ 。`?skip` 跳过开场，`?static` 关掉首屏粒子（看静态封面兜底）。
也可以在 Claude 桌面端用 launch 名 `portfolio-version-4` 启动。

## 这一版有什么

- **LOGO**：纯文字 SANSPHASE（下方小字“無相”），不用图形标志。
- **鼠标**：圆角、没有尾杆的箭头（白色填充 + 深色描边 + 一圈细白边，深色页面上也看得清），直接贴着系统鼠标、没有拖尾；可点的地方填成克莱因蓝；输入框里是文字光标。
- **首屏（不抄参考站）**：左边标题、简介、两个按钮、三个数字；右边一个浏览器窗口，里面是最新文章封面——约 8 万个粒子拼成，每 6.5 秒炸开重组成下一篇，鼠标移上去推出一个坑，点开进文章页。窗口下面是进度条和暂停键。不加其他装饰。
- **标题样式**：小菱形标记 + 逐词升起，蓝色强调词从窄到宽“长”出来，下面一条淡蓝墨带。
- **其余各区**：按参考站的顺序和结构——玻璃胶囊导航、双行速度跑马灯、三格 bento（3D 分层）、3D 屏幕轮播（可拖动）、数字格、宣言、社区（版块 + 发布记录热力图）、文章卡、栏目档案、联系横幅、描边大字页脚。
- 明暗两套主题，中英双语，⌘K / Ctrl K 搜索，文章阅读页（实时转发主站公开正文）。

## 多页面

导航栏现在跳到真正的独立页面，网址会变，浏览器前进 / 后退都能用，切页有淡出淡入：

| 网址 | 页面 | 内容（来自主站） |
| --- | --- | --- |
| `/` | 首页 | 原来的长页 |
| `/blog` | 博客 | 最新一篇大卡片 + 文章列表；分类筛选、搜索、网格 / 列表切换 |
| `/blog/<文章>` | 文章 | 阅读页（实时正文、目录）；关掉回到上一页 |
| `/work` `/learning` `/software` `/resources` | 作品 / 资料 / 软件推荐 / 资源中心 | 主站目前都是“整理中”，页面如实写明，并列出其他栏目 |
| `/community` | 社区交流 | 只留社区站入口（粒子从四周螺旋汇入一个被旋转文字环绕的圆形按钮，悬停时克莱因蓝从鼠标处铺满整张卡、粒子加速变白）+ “社区活跃度”面板：24 小时环形活跃图（指针指向北京时间此刻，最近 2 小时亮起）、当前在线人数、今日发帖 / 回复 / 签到 / 星尘流转小走势图、底部心跳线（每个尖峰是一次动态）。社区未开放，数字是**标明了的示意数据**；接真实数据只需替换 `pages.ts` 里的 `communityPulse()` |
| `/contact` | 联系与合作 | 承接内容、抖音和 QQ 群；注明正式联系方式仍在准备 |
| `/support` | 赞助与支持 | 主站原话：赞助渠道暂未开放 |
| 其他 | 404 | |

页脚和 ⌘K 搜索也都改成跳页面。本地预览由 `serve.mjs` 把这些网址都交给同一个页面处理。

## 和参考站的关系

参考：github.com/DingxinTao0417/tdx-portfolio（taodingxin.com）。按要求只照搬**区块顺序和导航分栏**。首屏构图、LOGO、鼠标、标题样式、动效和配色都是这一版自己的。第一轮评审发现首屏里还残留参考站的几个手法（极光背景、鼠标点亮的网格、斜体强调 + 手绘下划线、按钮流光描边、滚动时文案上浮/画面下沉、扫描线），已全部换掉。

## 内容来源与需要你确认的

- 文章、栏目、社区规则、备案号：`src/content.ts`（主站公开接口和 `src/data.mjs`，2026-10-17）。文章正文经 `serve.mjs` 转发主站公开接口，只放内存。
- 按主站改正了：方向是三个（AI 学习 · 创作过程 · 网站建设）；未开放栏目写“整理中 / In preparation”；社区写“筹备中”，不写“即将开放”；Codex 那篇按北京时间是 2026.09.25；作者签名按原文。
- 英文是翻译草稿，**需要你确认**：首屏标题 “Formless ideas, taking shape.”（“无形的想法，正在成相。”）、各区标题、文章标题与摘要。导航里原来的 “Work / 项目” 改成了 “Cases / 复盘”，因为主站的“作品”栏目还没有内容，展示的其实是四篇复盘。

## 质量检查

两轮多代理评审（运行逻辑、规则与需求、内容与双语、响应式与无障碍、对比参考站的完成度），每条结论都由另一个代理反驳核实。已修的包括：切换语言后标题不换、日志区挡住滚轮、轮播拖不动、导航在 1024–1279px 重叠、阅读页 / 菜单 / 搜索的键盘焦点、读屏器把数字读成 0–9、自动轮播没有暂停键、减少动态效果设置等。

## 已知限制

- 浏览器窗口在后台时动画会被降帧，属正常现象。
- 首屏粒子需要 WebGL；不支持时自动显示静态封面。
- 字体全部 OFL：Archivo、Inter、Noto Sans SC、JetBrains Mono。

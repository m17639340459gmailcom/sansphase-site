# 無相 · 个人网站

当前后端：**Payload 3.89.0 + SQLite**，运行在自己的电脑／服务器。日常编辑继续使用网站右上角的「作者模式」。访客页面、文章地址和配色沿用原版。

本地地址：http://127.0.0.1:4176/#/notes 。正式域名：www.sansphase.com。当前处于发布候选版整理阶段，尚未部署到腾讯云。

## 启动

需要 Node.js 24 LTS，以及 package.json 指定的 pnpm 版本。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

网站与 Payload 在同一个 Node 进程中运行。不需要再启动 8055 端口的 Directus。`node server.mjs` 和旧预览快捷命令也进入同一启动流程；配置缺失时明确失败，不显示假内容。

数据库和上传文件在 `.local/payload/`，私有运行配置在 `.local/payload-env.json`。这些文件不会进入公开构建目录。账号使用作者自己指定的邮箱和密码，不在代码或文档保存明文密码。

## 作者操作

- 公告：文字、海报、可选跳转链接、顺序、草稿、发布与撤回。
- 博客文章：正文编辑、文字颜色、表格、封面、标签、附件、草稿和发布。
- 资料与软件推荐：介绍、封面、下载文件、官方链接、草稿和发布。
- 个人信息：头像、名称、签名、简介和其他平台主页。
- 背景库：上传、保存、切换、移除和恢复。
- 音乐与配色：保留已有歌单链接、播放器设置和各类颜色设置。

## 备份和账号维护

```powershell
pnpm cms:backup
pnpm cms:account
```

备份包括一致的数据库快照、全部媒体、私有配置及校验清单。账号维护需在本机终端交互输入，新密码不显示；修改后旧会话退出。邮箱发信服务尚未配置，不能通过邮件找回密码。

恢复命令只写入**新的目录和配置文件**，拒绝覆盖现有数据库：

```powershell
pnpm cms:restore "备份目录" "新的数据目录" "新的配置文件.json"
```

切换到恢复数据需设置 `PAYLOAD_CONFIG_FILE`，验证后再启用。已提供备份定时任务模板，异地目标、保留周期和通知仍需在服务器配置。

## 验证

```powershell
pnpm build
pnpm test
pnpm test:author
pnpm test:publishing
pnpm release:prepare
```

作者与发布集成测试使用独立临时数据库，不创建或撤回作者真实文章。历史迁移、旧飞船与旧宇宙实现已归档，不参与当前构建和测试。测试数据仅在 tests 内供测试使用，不进入访客页面。

生产使用 `pnpm start`，必须设置 `NODE_ENV=production`、HTTPS 的 `SITE_ORIGIN` 和私有配置绝对路径。启动时校验构建文件，`/healthz` 返回运行版本与后端读取状态。

## 尚未完成的产品功能

天气使用访客授权定位并支持手动选城；时钟默认采用设备时区。音乐支持上传与可播放的音频直链，酷狗分享页仍为平台跳转，不能在本站直接播放整个酷狗账号歌单。浏览器可能阻止有声自动播放。

附件/安装包最多 15 GiB，图片 25 MiB，音乐 100 MiB，详情见 [上传说明](docs/UPLOAD-15GB.md)。限制不代表当前服务器磁盘能容纳这些文件。

社区注册讨论留到第二阶段；当前明确显示尚未开放。联系表单和支持收款未接通，不提供模拟提交。搜索引擎友好的文章地址、规模化服务端分页/搜索、邮件找回密码、集中媒体清理仍需后续建设。

生产部署还需腾讯云实机安装、域名与 HTTPS、访问限流、定时异地备份、恢复演练和运维监控。不能将“本地迁移完成”等同于“公网已部署”。

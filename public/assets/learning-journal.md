# AI 学习记录模板 / AI Learning Journal

这是 SANSPHASE 本地原型提供的示例文件，不是付费课程或已完成项目。
This is a sample file from the SANSPHASE local prototype.

## 本次想解决的问题 / Question
- 我想在什么场景下使用它？ / In what situation would this help?
- 预期看到什么结果？ / What result do I expect?

## 来源 / Sources
- 原始文档或资料链接 / Original documentation or resource
- 阅读日期与适用版本 / Date read and applicable version

## 我的实践 / My experiment
- 输入与准备 / Inputs and preparation
- 操作步骤 / Steps
- 实际结果 / Observed result
- 遇到的问题与解决办法 / Problems and solutions

## 下一步 / Next step
- 一个仍然没有答案的问题 / One open question
- 下一次最小的尝试 / The next small experiment

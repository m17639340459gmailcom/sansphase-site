# 作品整理清单 / Project Documentation Checklist

SANSPHASE 本地原型示例资料 / Local prototype sample resource

- [ ] 用一句话解释作品解决的问题 / Describe the problem in one sentence
- [ ] 说明你实际负责的部分 / Explain your contribution
- [ ] 准备有权使用的封面和截图 / Prepare a cover and screenshots you can use
- [ ] 记录关键选择与限制 / Record decisions and limitations
- [ ] 展示实际可验证的结果 / Show verifiable outcomes
- [ ] 提供演示地址或使用说明（如有） / Include a demo or instructions, if available
- [ ] 区分演示内容与已正式上线的功能 / Distinguish demos from released features
- [ ] 检查手机上的图片与阅读效果 / Check images and reading on mobile
- [ ] 整理版本和后续计划 / Record the version and next steps
